## Что ещё не проверено

Настоящий X11-дисплей, запуск через FUSE, аппаратное ускорение и сборка Windows.
Матрицы совместимости по дистрибутивам пока нет.

В контейнерах на NixOS AppImage проверяется извлечением SquashFS и запуском
`AppRun`: прямому запуску может мешать обработчик binfmt хоста. Проверка Wayland
через `appimage-run` в ограниченном окружении возвращала `Operation not permitted`;
запуск через Docker и сокет дисплея прошёл успешно.

## Повторная проверка

Из каталога `client-v2`:

```sh
(cd dist-appimage-ui2 && sha256sum --check SHA256SUMS)
./scripts/verify-appimage-clean.sh \
  dist-appimage-ui2/RuTool-2.0.8-x86_64.AppImage build-linux-validation
```

Скрипты сборки сохраняют `appdir-smoke.png` и `appimage-smoke.png` рядом с AppImage.
Проверка в чистом контейнере сохраняет `clean-smoke.log` и `clean-smoke.png`
в указанный каталог.

Инструкция по сборке и запуску: [BUILDING-LINUX.md](../BUILDING-LINUX.md).
