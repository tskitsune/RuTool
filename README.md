# RuTool Installer 2.0.8 — Linux

Linux-версия RuTool для Blue Archive. Работают поиск игры, скачивание и установка
перевода, восстановление оригинальных файлов.

**Linux x86_64, glibc ≥2.39.** Qt включён в AppImage.

[Скачать AppImage](https://github.com/tskitsune/RuTool/releases/tag/v2.0.8-linux) · [Сборка и запуск](client-v2/BUILDING-LINUX.md)

**Steam Deck** — работа проверена.

1. Переключись в режим рабочего стола (Desktop Mode) и скачай AppImage по ссылке выше.
2. Открой свойства скачанного файла и разреши его запуск как программы.
3. Запусти AppImage двойным щелчком.
